# 时间分层预测：5 个假设的演化路径

**所属探索**：Exploration 0001 — AI 时代软件价值的初步研究  
**阶段**：阶段 1 - 发现与理解（深层研究）  
**创建日期**：2026-01-19  
**文档目的**：对 5 个假设进行 0-2 年、2-5 年、5-10 年的分层预测，定义每层的关键里程碑和决策点，帮助识别"现在该做什么"和"什么时候该调整"。

---

## 0. 方法论：为什么需要时间分层

### 0.1 核心问题

预测不是"猜未来会发生什么"，而是"在不同时间尺度上，什么变化最可能发生？什么决策需要在什么时候做出？"

> **0-2 年**：技术可行性 + 早期采用者行为（最确定）  
> **2-5 年**：主流市场渗透 + 商业模式验证（中等确定）  
> **5-10 年**：结构性变化 + 生态重塑（最不确定）

### 0.2 分层预测原则

1. **短期（0-2 年）**：基于现有技术轨迹和早期采用者行为，预测相对确定
2. **中期（2-5 年）**：基于市场渗透曲线和商业模式演化，预测中等确定
3. **长期（5-10 年）**：基于结构性变化和生态重塑，预测高度不确定，但方向可识别

### 0.3 每层预测包含

- **关键里程碑**：什么事件标志着该阶段的进展？
- **决策点**：在什么时间点需要做出什么决策？
- **不确定性来源**：什么因素可能导致预测偏离？
- **信号指标**：用什么领先指标监测该阶段的进展？

## 1. HYP-001：小企业 AI 工作流助手

### 1.1 0-2 年预测（2026-2028）

**主题**：技术可行性验证 + 早期采用者获取

**关键里程碑**：
- **M1（0-6 个月）**：完成用户访谈，识别 Top 3 工作流痛点
- **M2（6-12 个月）**：构建 MVP，集成 5-10 个常用工具（如微信/钉钉/飞书/企业微信）
- **M3（12-18 个月）**：获取 50 个付费用户，验证付费意愿
- **M4（18-24 个月）**：用户留存率 > 60%，NPS > 30

**决策点**：
- **D1（6 个月）**：基于用户访谈，决定是否继续（Go/No-Go）
  - Go 条件：≥ 60% 受访者表示"愿意付费"
  - No-Go 条件：< 40% 受访者表示"愿意付费"
- **D2（12 个月）**：基于 MVP 数据，决定是否扩大投入
  - Go 条件：50 个付费用户，留存率 > 50%
  - Pivot 条件：付费用户 < 20，或留存率 < 30%
- **D3（24 个月）**：基于商业模式验证，决定是否规模化
  - Go 条件：ARR > ¥500K，LTV/CAC > 3
  - No-Go 条件：ARR < ¥200K，或 LTV/CAC < 1.5

**不确定性来源**：
- 大厂（钉钉/飞书/企业微信）快速跟进 AI 工作流功能
- 小企业对"AI 自动化"的信任度低
- 集成复杂度超出预期

**信号指标**：
- 开发者行为：Zapier/Make 新连接器数量、n8n Star 增长
- 投资流向：SMB SaaS 融资数量、AI workflow 工具融资
- 技能需求："AI workflow" 岗位数量

### 1.2 2-5 年预测（2028-2031）

**主题**：主流市场渗透 + 商业模式验证

**关键里程碑**：
- **M5（2-3 年）**：用户数达到 1000 家小企业，ARR > ¥5M
- **M6（3-4 年）**：建立行业垂直解决方案（如餐饮/零售/服务业）
- **M7（4-5 年）**：成为某个垂直领域的标准工具，市场份额 > 10%

**决策点**：
- **D4（3 年）**：决定是否进入垂直行业
  - Go 条件：某个行业用户占比 > 30%，且留存率 > 70%
  - No-Go 条件：用户分散，无明显行业集中
- **D5（5 年）**：决定是否被并购或独立发展
  - 并购条件：大厂报价 > 10x ARR
  - 独立条件：ARR > ¥20M，增长率 > 50%

**不确定性来源**：
- 小企业管理者对"AI 替代人工"的抵触
- 数据隐私和合规要求增加
- 经济下行导致小企业缩减 IT 支出

**信号指标**：
- 投资流向：SMB SaaS 估值倍数、并购事件
- 技能需求："SMB automation" 岗位数量
- 专利引用："AI workflow automation" 专利数量

### 1.3 5-10 年预测（2031-2036）

**主题**：结构性变化 + 生态重塑

**关键里程碑**：
- **M8（5-7 年）**：AI Agent 成为小企业"数字员工"，工作流自动化从"工具集成"升级为"自主决策"
- **M9（7-10 年）**：小企业软件生态从"人使用工具"转变为"AI Agent 协作网络"

**决策点**：
- **D6（7 年）**：决定是否扩展到"AI Agent 平台"
  - Go 条件：平台效应显现，第三方开发者 > 100
  - No-Go 条件：生态封闭，增长停滞

**不确定性来源**：
- AI Agent 的自主决策引发法律和责任问题
- 大厂（钉钉/飞书/企业微信）完全整合 AI 工作流
- 小企业对"AI 控制业务流程"的接受度

**信号指标**：
- 开发者行为：AI Agent 开源项目数量
- 投资流向：AI Agent 平台融资
- 专利引用："autonomous AI agent" 专利数量

## 2. HYP-002：Family OS（家庭操作系统）

**主题**：需求验证 + 产品定义

**关键里程碑**：
- **M1（0-6 个月）**：完成 20 个家庭深度访谈，识别 Top 3 协调痛点

- **M4（18-24 个月）**：付费转化率 > 5%，用户留存率 > 40%

**决策点**：
- **D1（6 个月）**：基于家庭访谈，决定是否继续

- **D3（24 个月）**：基于商业模式验证，决定是否规模化
  - Go 条件：付费用户 > 500，ARR > ¥200K
  - No-Go 条件：付费用户 < 200，或 ARR < ¥100K

- 家庭成员对"统一工具"的抵触（习惯差异）
- 隐私担忧（家庭数据敏感）
- 付费意愿低（消费者 SaaS 通病）

**信号指标**：
- 开发者行为：家庭协作类 App 新上线数量、"family organizer" GitHub 项目数

**关键里程碑**：
- **M5（2-3 年）**：用户数达到 10,000 个家庭，ARR > ¥2M
- **M6（3-4 年）**：扩展至"家庭财务协调""家庭任务分配"等场景

- **D4（3 年）**：决定是否扩展到更多场景
  - Go 条件：单一场景留存率 > 60%，用户请求更多功能
  - No-Go 条件：留存率 < 40%，用户不活跃

  - No-Go 条件：用户活跃度 < 50%，只使用核心功能

**不确定性来源**：

- 技能需求："consumer SaaS PM" 岗位数量
- 专利引用："family management software" 专利数量

- 现有解决方案（师傅带徒弟/视频学习）已满足需求

**信号指标**：
- 开发者行为：图像识别 API 在维修场景的调用量、"trade skills" App 数量
- 投资流向：BlueCollar Tech 融资数量、AR/VR 培训融资
- 技能需求："computer vision engineer" 岗位数量

### 5.2 2-5 年预测（2028-2031）

**主题**：场景扩展 + 商业模式验证

**关键里程碑**：
- **M5（2-3 年）**：覆盖 5 个维修场景（如电器/汽车/管道/装修/设备），用户数达到 50,000 技工
- **M6（3-4 年）**：扩展至"技能认证""工作匹配"等场景
- **M7（4-5 年）**：建立商业模式（技能认证/工作佣金/培训服务），ARR > ¥10M

**决策点**：
- **D4（3 年）**：决定是否扩展到更多维修场景
  - Go 条件：单一场景留存率 > 60%，用户请求更多场景
  - No-Go 条件：留存率 < 40%，用户不活跃
- **D5（5 年）**：决定是否引入"工作匹配服务"（如接单平台）
  - Go 条件：用户活跃度 > 70%，愿意尝试接单
  - No-Go 条件：用户活跃度 < 50%，只使用学习功能

**不确定性来源**：
- 蓝领招聘平台（如鱼泡网）推出类似功能
- 技工付费意愿低
- 技能认证缺乏行业标准

**信号指标**：
- 投资流向：BlueCollar Tech 估值倍数、并购事件
- 技能需求："AR/VR developer" 岗位数量
- 专利引用："image recognition repair" 专利数量

### 5.3 5-10 年预测（2031-2036）

**主题**：蓝领数字化基础设施 + 生态重塑

**关键里程碑**：
- **M8（5-7 年）**：成为蓝领"技能发展平台"，连接学习/认证/工作/社交
- **M9（7-10 年）**：AI 助手成为"技能导师"，主动提供职业发展建议

**决策点**：
- **D6（7 年）**：是否开放平台，引入第三方服务（培训/认证/金融）
  - Go 条件：用户基数 > 500K，平台效应显现
  - No-Go 条件：用户基数 < 200K，生态封闭

**不确定性来源**：
- 蓝领对"AI 职业发展建议"的接受度
- 数据隐私和所有权问题
- 蓝领招聘平台完全整合 AI 功能

**信号指标**：
- 开发者行为：蓝领技能 API 调用量
- 投资流向：BlueCollar Tech 平台融资
- 专利引用："vocational training AI" 专利数量

## 6. 跨假设时间分层观察

### 6.1 共同模式

1. **0-2 年：所有假设都聚焦"需求验证 + MVP 测试"**
   - 共同挑战：用户访谈设计、MVP 构建、早期用户获取
   - 共同决策点：6 个月（Go/No-Go）、12 个月（扩大测试）、24 个月（规模化）

2. **2-5 年：所有假设都聚焦"功能扩展 + 商业模式验证"**
   - 共同挑战：场景扩展、商业模式设计、竞争应对
   - 共同决策点：3 年（场景扩展）、5 年（服务扩展）

3. **5-10 年：所有假设都聚焦"平台化 + 生态重塑"**
   - 共同挑战：平台开放、生态构建、结构性变化应对
   - 共同决策点：7 年（平台开放）

### 6.2 关键差异

| 假设 | 0-2 年核心挑战 | 2-5 年核心挑战 | 5-10 年核心挑战 |
|------|---------------|---------------|----------------|
| HYP-001 | 集成复杂度 | 大厂竞争 | AI Agent 自主决策 |
| HYP-002 | 家庭使用意愿 | 网络效应构建 | 家庭数字化基础设施 |
| HYP-003 | 农户信任建立 | 区域扩张 | 农业数字化基础设施 |
| HYP-004 | 无障碍设计 | 服务整合 | 老年人数字化基础设施 |
| HYP-005 | 技术可行性 | 场景扩展 | 蓝领数字化基础设施 |

### 6.3 共同不确定性

1. **大厂竞争**：所有假设都面临大厂（钉钉/飞书/Apple/Google/微信）快速跟进的风险
2. **用户付费意愿**：所有假设都面临用户付费意愿低的挑战
3. **AI 接受度**：所有假设都面临用户对"AI 建议/决策"的接受度问题

### 6.4 共同信号指标

1. **开发者行为**：GitHub Star 增长、API 调用量、开源项目数量
2. **投资流向**：融资数量、估值倍数、并购事件
3. **技能需求**：相关岗位数量、薪资变化
4. **专利引用**：相关专利数量、引用网络

## 7. 下一步行动

### 7.1 立即做（0-6 个月）

1. **为每个假设建立时间线**：
   - 明确 0-2 年的关键里程碑和决策点
   - 设置信号指标监测系统

2. **执行 6 个月决策点**：
   - 完成用户访谈
   - 基于 Go/No-Go 条件做出决策

### 7.2 短期（6-24 个月）

1. **构建 MVP 并测试**：
   - 基于用户反馈迭代产品
   - 验证付费意愿和使用留存

2. **执行 12 个月和 24 个月决策点**：
   - 基于数据决定是否扩大测试或规模化

### 7.3 中期（2-5 年）

1. **扩展功能和场景**：
   - 基于用户需求扩展产品功能
   - 验证商业模式

2. **执行 3 年和 5 年决策点**：
   - 基于数据决定是否扩展场景或服务

### 7.4 长期（5-10 年）

1. **构建平台和生态**：
   - 开放平台，引入第三方开发者和服务
   - 应对结构性变化

2. **执行 7 年决策点**：
   - 基于数据决定是否开放平台
