# Skills 目录

本目录包含项目使用的 Agent Skills。

## 已集成的 Skills

### 女娲.skill (nuwa-skill)

**作者**：花叔 (Huashu)  
**许可证**：MIT  
**仓库**：https://github.com/alchaincyf/nuwa-skill

女娲是一个 AI Skill 蒸馏工具，能够自动提取公众人物的思维方式——心智模型、决策启发式、表达 DNA——生成可独立使用的 AI 思维顾问。

#### 核心能力

- **六路并行调研**：著作、对话、表达、批评、决策、时间线
- **三重验证提炼**：跨域复现性、问题生成力、认知独特性
- **认知 Skill 生成**：心智模型、决策启发式、表达特征、价值观、反模式、适用边界
- **质量验证**：已知问题测试、边缘问题测试、风格测试

#### 已蒸馏人物

女娲已蒸馏 17+ 位人物，包括：
- 乔布斯、马斯克、芒格、费曼
- Naval、塔勒布、Paul Graham
- 张雪峰、罗永浩、张一鸣
- Karpathy、Ilya Sutskever
- 等

#### 在 Noos Enterprise 中的应用

女娲 skill 与本项目的探索方法高度契合：

1. **产品探索**：用不同思想框架评估产品方向
2. **用户研究**：从不同视角理解用户需求
3. **决策分析**：用顶级思考者的方法论评估假设
4. **知识蒸馏**：将行业专家的方法论结构化

#### 使用示例

```
# 用乔布斯视角评估产品
用户 ❯ 我们应该做功能丰富的产品还是极简产品？
乔布斯 ❯ 聚焦即说不。极简不是少，是恰到好处。

# 用芒格视角评估风险
用户 ❯ 这个市场值得进入吗？
芒格 ❯ 先想怎么会失败。逆向思考，然后避免。

# 用马斯克视角评估成本
用户 ❯ 获客成本太高怎么办？
马斯克 ❯ 先算物理极限。不是优化漏斗，是质疑漏斗本身。
```
